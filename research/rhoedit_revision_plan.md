## 4. 顺序扩展应如何定义

令第 k 轮输入为 D_k，起点为 theta_(k-1)，终点为 theta_k。当前编辑梯度为 g_k，编辑曲率为 C_edit,k，保留曲率代理为 C_ret,k-1。采用原 Eq. (5) 的形式：

    g_adj,k = (I + lambda C_ret,k-1 C_edit,k^(-1))^(-1) g_k.

Algorithm 2 建议明确以下步骤：

1. 在 theta_0 和能力参考集上初始化保留因子。
2. 第 k 轮只访问已到达的当前编辑集合，不能用未来编辑估计曲率或调参。
3. 在 theta_(k-1) 上估计当前编辑因子，并与历史保留因子计算广义谱。
4. 在本轮内部固定因子，过滤梯度并进行若干优化步。
5. 在 theta_k 上重新估计本轮数据因子。
6. 按指定归一化权重将本轮因子并入历史状态。
7. 评估当前编辑、历史编辑、邻近事实和原有能力。

如保留当前实现的因子递推，应明确它是因子化代理：

    A_bar,k = (M_(k-1) A_bar,k-1 + T_k A_post,k) / (M_(k-1) + T_k)
    B_bar,k = (M_(k-1) B_bar,k-1 + T_k B_post,k) / (M_(k-1) + T_k)
    C_ret,k ≈ A_bar,k ⊗ B_bar,k.

不能把它等同于 sum_j w_j (A_j ⊗ B_j)。分别平均因子产生跨来源项；各轮还可能在不同参数点估计。它是可计算的历史几何代理，不是严格累积 Fisher。

### 4.1 原始锚点与局部锚点必须区分

原论文的保护目标是相对 theta_0 的能力 KL。若将每轮参考改成 theta_(k-1)，控制的是相邻轮次漂移，不能据此推出最终模型接近 theta_0。

同样，如果保护历史编辑 j 时采用其完成时模型 theta_j 作为教师，那么在 theta_(k-1) 上，历史 KL 的梯度一般不为零；不能直接复用 Eq. (2) 中零一阶项的推导。

推荐将顺序算法写成“受局部模型启发的实际扩展”，分别报告相邻轮次漂移和相对原始模型的累计漂移。若要给全序列理论保证，需要另行定义锚点、误差项和预算，不能靠替换下标得到。

### 4.2 能力状态被稀释的问题

当前因子平均中，原始能力因子的系数为 M_0/(M_0+sum T_j)，会随历史长度下降。可增加固定能力/历史混合比例的对照，但不要无实验就将其替换为主算法。

若采用 C_ret=alpha C_cap+(1-alpha)C_hist，通常会得到多个 Kronecker 积的和。它一般不能直接沿用当前两因子谱分解，需要再次因子近似或新的求解方式，成本与近似也要交代。

### 4.3 不要提前宣称常数总内存

曲率状态在固定模型尺寸下可不随轮次数增长，但当前代码还保存历史文本/目标列表用于评估。必须分别报告编辑器状态、评估数据缓存、模型和优化器状态，才能说明可扩展性。

## 5. 最小实验矩阵

先用 Llama-3-8B + ZsRE，3,000 条事实，每轮 100 条，共 30 轮；这是建议协议，不是现有论文实验的重解释。所有方法使用同样划分、顺序、训练预算和评估集。先排除同一事实被重复改写的矛盾，再另设事实再更新实验。

核心采用 2×2 因子设计：

| 编辑侧几何 | 固定能力保留状态 | 能力+历史动态状态 |
|---|---|---|
| I（匹配尺度） | capability-only / fixed | capability-only / dynamic |
| 当前编辑曲率 | relative / fixed | relative / dynamic |

另加 Adam 与实际更新范数匹配的 Adam。I 基线使用匹配的曲率尺度或公平的 lambda 搜索；仅替换矩阵而不处理尺度会混淆机制。匹配 Adam.step 后的参数增量，不只匹配输入梯度范数。

这是机制消融，不可将 capability-only 变体标为 FisherEdit 复现。正式方法比较需核查并实现其完整算法。

必报指标：

- 当前轮 WILD reliability/generalization，以及前后编辑成功变化。
- 历史批次保留矩阵 R_(k,j)：第 k 轮后对第 j 批的成功率。
- 历史遗忘：平均 R_(j,j)-R_(k,j)，并同时报告初次学习水平，避免初始没学会被误判为少遗忘。
- 原始能力的分任务变化、均值和最大退化；wiki loss 或 token accuracy 只能作过程诊断。
- 无关事实与邻近事实局部性，区分于历史编辑保持。
- 每轮参数更新范数、相对原始参数的累计变化，以及可行时的真实输出 KL。
- 曲率估计、分解、编辑更新、评估的独立耗时；峰值显存和曲率缓存大小。

三个配对随机种子/顺序作为初始建议，同时记录参考集抽样与采样标签随机性。报告配对差异和区间，不将 3 次重复视为充分精度保证。完成小规模后再扩展到 10,000 条/100 轮、CounterFact 和 Qwen。优先覆盖 Qwen CounterFact，因为原 Table 3 上 LocFT-BF 同时领先编辑均值与能力均值。

建议主文新增三幅图：历史保留热图；当前学习/历史保留/通用能力随轮次的三联图；统一调参预算下的编辑—保留权衡图。新增一张机制消融表，现有 n 和 lambda 扫描可压缩或移至附录。

- 新增局限：曲率估计近似、跨参数块忽略、固定轮内几何、陈旧历史曲率、Adam 替代二阶更新、参考集覆盖有限。

## 7. 推荐执行顺序与验收点

1. 固定论文表格对应的实验版本：提交、配置、曲率缓存来源、优化步数和评估脚本可追溯。
2. 修正文稿与代码口径，尤其模型 Fisher/观测标签估计；不在此阶段声称新性能。
3. 跑 30 轮机制试验，确认相对几何与动态历史状态各自有可观察贡献。
4. 若收益只来自更新幅度，调整贡献表述；若动态历史状态有效但相对曲率无额外收益，也应如实收缩主张。
5. 扩展模型、数据集和序列长度，并完成基线与成本诊断。
6. 根据最终结果重写 Abstract、Introduction、Sec. 3.4 和 Conclusion，填入真实数值。

在证据尚不足时，采用“原方法 + 经验证的顺序扩展”最稳妥。论文最终贡献应由对照结果决定，不由 FisherEdit 摘要中的叙事决定。
