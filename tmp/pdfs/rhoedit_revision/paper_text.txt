ABSTRACT
Model editing aims to change a specific fact or behavior while leaving the rest
of the model working as before. This is difficult because parameter updates can
damage unrelated knowledge and general capabilities. We introduce RHOEDIT,
which formulates capability-preserving model editing as constrained optimization
and derives a relative-curvature gradient adjustment from a local second-order
model. The adjustment jointly uses edit and capability curvature, attenuating each
gradient component more strongly along directions of greater relative capability
sensitivity. It thereby retains useful editing directions while protecting the be-
havior represented by a capability reference set. We approximate both curvatures
with Kronecker-factored approximate curvature to make the adjustment practical
for LLMs. Across ZsRE, CounterFact, and WikiBigEdit, RHOEDITachieves an
average editing score of 68.8 while retaining nearly all of the unedited model’s
general capabilities (65.1 versus 65.4). Compared with AlphaEdit, RHOEDITim-
proves editing by 1.8 points and general capabilities by 18.5 points; compared
with CrispEdit, it improves editing by 6.8 points while slightly improving gen-
eral capabilities. These results show that relative curvature improves the balance
between model editing and capability preservation.
1 INTRODUCTION
Large language models (LLMs) acquire broad knowledge and skills during pretraining. After train-
ing, however, facts change, errors are discovered, and applications may require new behavior. Re-
training the entire model for every small correction is expensive and slow. Model editing studies
how to change a specific fact or behavior without rebuilding the model from scratch (Sinitsin et al.,
2020; De Cao et al., 2021; Yao et al., 2023; Wang et al., 2024c). Its goal is simple to state: make the
intended change while leaving the rest of the model working as before.
This goal is difficult because a language model does not expose its knowledge as independent records
that can simply be replaced (Geva et al., 2021; Dai et al., 2022; Meng et al., 2022). The same
parameters contribute to many predictions, so an update for one prompt can also change answers
to other prompts. If the update is too limited, the model may reproduce the new answer only for
the exact wording it has seen. If the update is too broad, it may damage unrelated knowledge
or general skills. Model editing must therefore make the requested change while preserving the
model’s existing abilities.
Research on model editing has developed along several complementary paths. Early work trained
neural networks to accept targeted updates or learned an editor that predicts parameter changes from
edit examples (Sinitsin et al., 2020; De Cao et al., 2021; Mitchell et al., 2022a). Locate-then-edit
methods later identified layers or representations associated with a fact and modified only those parts
of the model (Dai et al., 2022; Meng et al., 2022; 2023). In parallel, memory- and adapter-based
methods kept the base model largely unchanged and stored new behavior in additional components
(Mitchell et al., 2022b; Hartvigsen et al., 2023; Yu et al., 2024; Wang et al., 2024a). Drawing on
constrained optimization and continual learning, another line restricted parameter updates to protect
representations or directions considered important to existing behavior (Zhu et al., 2020; Wang et al.,
2021; Fang et al., 2025; Ikram et al., 2026). Together, these approaches have expanded model editing
from isolated factual corrections to settings with many edits.

Despite these improvements, existing methods typically either derive updates primarily from edit
information or structural assumptions (Yang et al., 2025b; Gu et al., 2026; Meng et al., 2022; 2023;
Pan et al., 2025) or use a single preservation set as a proxy for the model’s broader capabilities when
selecting admissible update subspaces (Fang et al., 2025; Ikram et al., 2026), leading to a suboptimal
trade-off between editing efficacy and preservation.
In this paper, we introduce RHOEDIT, an editor that jointly uses edit and capability curvature to
balance learning new behavior with retaining existing behavior. Figure 1 illustrates how our full-
space adjustment retains useful editing directions excluded by a capability-only subspace constraint
while maintaining strong preservation, thereby achieving a better edit–preservation trade-off. Our
approach builds on three core ideas.
1. Gradient adjustment via relative curvature.We formulate editing as a constrained optimiza-
tion problem, solve a local second-order model of it in closed form, and identify within the solution
a gradient adjustment that measures capability curvature relative to edit curvature. The adjustment
then shrinks the gradient along each direction by the capability that direction costs per unit of edit
progress.
2. A common curvature geometry for editing and preservation.We formulate both edit and
capability curvature using generalized Gauss–Newton matrices and show that they coincide with
the model Fisher information matrices in our setting. These matrices measure how sensitive the
model’s predictions are to parameter changes on edit and capability data. This connects the relative-
curvature adjustment to predictive sensitivity and enables both curvatures to be estimated using the
same computational tools.
3. Scalable K-FAC realization for LLMs.Applying the joint-curvature adjustment directly would
require matrices too large to construct for LLMs. We approximate both edit and capability curvature

3 RELATIVE-CURVATUREGRADIENTADJUSTMENT FORMODELEDITING
Model editing seeks progress on the requested behavior while limiting changes to the behavior to
preserve. The key idea of RHOEDITis to adjust the edit gradient according to capability curvature
relative to edit curvature. Components with larger relative capability curvature receive stronger
attenuation, while those with smaller relative capability curvature retain more of the edit gradient.
We begin in Section 3.1 by deriving a local second-order model of the model editing problem formu-
lated in equation 1 and solving it in closed form, revealing a relative-curvature gradient adjustment.
Then, we derive a Gauss–Newton formulation of the adjustment in Section 3.2, and make the ad-
justment computable at LLM scale in Section 3.3.

4 EXPERIMENTS
4.1 SETUPS
We primarily focus on editing Llama-3-8B-Instruct. For cross-model evaluation, we use Qwen2.5-
7B-Instruct and report the results in Appendix E.
Datasets and Evaluation.We conduct experiments on 3,000 samples of three standard model
editing datasets: ZsRE (Levy et al., 2017), CounterFact (Meng et al., 2022), and WikiBigEdit (Thede
et al., 2025). We report two standard model-editing metrics (De Cao et al., 2021; Yang et al.,
2025a):reliability(also known as efficacy), which assesses whether the edited model produces an
acceptable response to the original edit prompt, andgeneralization, which assesses whether the edit
transfers to semantically related paraphrases of that prompt. We follow WILD (Yang et al., 2025a),
which combines context-guided autoregressive decoding with LLM-as-a-judge scoring, and adopt it
through EasyEdit (Wang et al., 2024b), evaluating prompts both with and without QA context. To

4.2 MAINRESULTS
Across the three datasets, we observe two patterns. First, sacrificing base capabilities does not guar-
antee effective editing: FT and LocFT-BF substantially degrade these capabilities yet achieve limited
editing success, while MEND and MEMIT exhibit severe degradation and fail on both edit reliability
and generalization. AlphaEdit achieves strong overall editing performance but also substantially de-
grades base capabilities. Second, methods that largely preserve base capabilities, including LoRA,
UltraEdit, and CrispEdit, leave room for better editing; CrispEdit is strongest among these on ZsRE
and CounterFact, whereas UltraEdit leads on WikiBigEdit. In comparison,RHOEDITachieves the
strongest overall editing performance among methods that largely preserve base capabilities
across all three datasets. It leads all methods on ZsRE and trails only AlphaEdit on CounterFact
and WikiBigEdit, while keeping overall capability close to that of the unedited model.

5 RELATEDWORK
Model editing paradigms.Model editing methods differ in where they store an edit and how
they compute the update. Memory-based editors attach auxiliary models, memories, or adapters
and route relevant inputs through them (Dong et al., 2022; Mitchell et al., 2022b; Hartvigsen et al.,
2023; Yu et al., 2024; Wang et al., 2024a). Meta-learned editors predict parameter changes from
edit examples or gradients (Mitchell et al., 2022a; Tan et al., 2024; Li et al., 2025). Locate-then-edit
methods identify layers or representations associated with a fact and modify selected weights (Dai
et al., 2022; Meng et al., 2022; 2023; Pan et al., 2025). Fine-tuning methods directly optimize model
parameters for the requested behavior (Zhu et al., 2020; Wang et al., 2021; Yang et al., 2025b).
Capability-preserving fine-tuning.Fine-tuning-based editors optimize an edit loss while limiting
changes to existing behavior through weight regularization (Zhu et al., 2020), restricted layers (Yang
et al., 2025b), or projected gradients (Wang et al., 2021). Layer restrictions determine where an up-
date can occur; importance penalties and projections use estimates of which changes might harm re-
tained behavior. Related continual-learning methods assign larger penalties to parameters important
for earlier tasks, using Fisher information in elastic weight consolidation (Kirkpatrick et al., 2017)
or accumulated parameter contributions in synaptic intelligence (Zenke et al., 2017). Among editing
methods, CrispEdit projects gradients onto low-curvature directions of a capability objective (Ikram
et al., 2026); AlphaEdit applies a null-space projection to a locate-then-edit update (Fang et al.,
2025). These projection methods select admissible directions using preservation-side information.
As a fine-tuning method, RHOEDITalso accounts for the local curvature of the edit loss. Derived
from a constrained editing objective, its adjustment scales gradient components by capability curva-
ture relative to edit curvature.
6 CONCLUSION
Effective editing and capability preservation can coexist when a model update is judged by both the
requested change and the behavior it may disturb. We formalized this balance as a constrained edit-
ing problem and derived RHOEDITto adjust the edit gradient using capability curvature relative to
edit curvature. The adjustment protects sensitive existing behavior while keeping directions that re-
main useful for the edit available. A scalable curvature approximation makes this principle practical
for LLMs. Across our evaluations, RHOEDITmakes effective edits while measured general capabil-
ities remain close to their original level, including when the number of edits grows. Together, these
results suggest that preserving a model’s broader usefulness requires considering what each update
can accomplish alongside what it might disrupt.

D.5 COMPUTATIONALCOMPLEXITY
We compare the dense and K-FAC realizations for one weight blockW∈R m×n, with curvature
fixed and the decomposition reused throughout an edit. The following costs concern the linear
algebra after curvature estimation; data passes for estimating curvature and the storage of model
parameters and optimizer state are excluded.
In the dense realization, each curvature matrix has sizemn×mn. Cholesky whitening followed by
a symmetric eigendecomposition costsO((mn) 3) =O(m 3n3)once. Each subsequent adjustment
applies the forward and inverse gradient-coordinate transformations, each a dense matrix–vector
product in dimensionmn, for a total ofO((mn) 2) =O(m 2n2). The curvature matrices and bases
requireO(m 2n2)memory, which dominates theO(mn)gradient storage.
With K-FAC, the corresponding Cholesky factorizations and eigendecompositions operate on the
m×mandn×nfactors, costingO(m 3 +n 3)once. For the forward transformationQ ⊤
BgeditQA,
the left multiplication costsO(m 2n)and the right multiplication costsO(mn 2). The inverse trans-
formation in equation 17 has the same cost, while elementwise attenuation costsO(mn), giving
O(m2n+mn 2)per adjustment. The factors and their bases occupyO(m 2 +n 2)memory, and the
gradient and intermediate matrices occupyO(mn). Neither the full curvature matrices nor the joint
basisQ ⊗ are formed, so the total auxiliary memory isO(m 2 +n 2 +mn).
For a square block withm=n=d, K-FAC reduces the decomposition cost fromO(d 6)toO(d 3),
the cost per gradient fromO(d 4)toO(d 3), and auxiliary memory fromO(d 4)toO(d 2). Since the
block containsd 2 weights, the last reduction makes the retained curvature state scale linearly with
the parameter count.
